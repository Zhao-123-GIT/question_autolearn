# 机械制造工艺学终极刷题库 V3

针对《机械制造工艺学》期末复习与阶段测试专门定制的纯前端离线刷题应用。

## 🌟 项目特性

- **数据全内置**：无缝集成了题库 PDF 中的全部 **98 道精选题**（48道单选题，50道判断题）。
- **极简无依赖**：纯原生 `HTML5`、`CSS3`、`JavaScript (ES6)` 开发，**严禁且无需** Vue/React 框架、无需搭建 Node.js 后端服务。
- **离线安全免联网**：双击 `index.html` 即可在任意浏览器全功能平稳运行，无服务器及数据库压力。
- **完备的驾考辅助体验**：
  - 支持**顺序刷题**、**随机抽取20题**练习以及**模拟考试**模式。
  - **模拟考试模式**严格按照 30道单选 + 20道判断（共50题）进行随机动态组卷，交卷后支持自动核算总分与正确率，并呈现详细解析。
  - **驾考宝典导航**：顶部状态面板和侧边栏指示灯实时呈现已答（绿色）与未答（红色）状态，点击可秒级跳转。
  - **自动保存**：依托 `localStorage`，刷新或意外关闭浏览器后作答进度永不丢失。
  - 拥有独立的**错题本**自动记录和关键词**模糊检索**系统。
  - 完美适配手机优先响应式卡片圆角设计，且支持一键切换**浅色/深色主题**。

## 🚀 启动与使用指南

1. 将生成的 `index.html`、`style.css`、`app.js`、`questions.js` 集中存放在一个名为 `project/` 的文件夹下。
2. 找到 `project/index.html` 文件，双击或者用任意现代浏览器（Chrome、Edge、Safari 等）打开即可直接开始高效刷题。
